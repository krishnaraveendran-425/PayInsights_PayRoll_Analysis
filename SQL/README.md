# PayInsight Payroll Analysis — SQL

## Overview
This folder contains the SQL queries used to analyze fictional employee payroll data for the PayInsight project.

## Tools
- MySQL 8.0
- MySQL Workbench

## Analysis Performed
- Total employees and overall payroll summary
- Top 5 employees by net salary
- Average net salary by department
- Employees earning above the average net salary
- Gross payroll by department
- Overtime hours and overtime costs
- Salary deductions by department
- Payroll calculation validation

## Key Results
- **Total employees:** 30
- **Total gross payroll:** ₹11,37,105
- **Total deductions:** ₹1,99,551
- **Total net payroll:** ₹9,37,554
- **Average net salary:** ₹31,251.80

## Files
- `payroll_analysis.sql` — SQL queries used for payroll analysis.

## Dataset Note
The dataset contains fictional employee records created for educational and portfolio purposes. It does not represent real company payroll data.
