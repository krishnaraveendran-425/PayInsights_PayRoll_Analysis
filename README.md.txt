# PayInsight Payroll Analysis – SQL Project

## Project Overview
PayInsight Payroll Analysis is a beginner-friendly data analytics project that uses SQL to analyze employee payroll data. The project focuses on employee salaries, payroll costs, salary deductions, and overtime payments.

The dataset contains 30 sample employee records created for learning and portfolio purposes. It does not represent actual company payroll data.

## Objectives
- Analyze employee salary information.
- Identify employees with the highest net salaries.
- Compare average net salaries across departments.
- Calculate total gross payroll and net payroll.
- Analyze overtime hours and overtime costs.
- Examine employee deductions.
- Validate payroll calculations using SQL.

## Tools Used
- **MySQL 8.0** – Data querying and analysis
- **MySQL Workbench** – Writing and executing SQL queries
- **GitHub** – Project documentation and portfolio

## Key Findings
- Total employees analyzed: 30
- Total gross payroll: ₹11,37,105
- Total deductions: ₹1,99,551
- Total net payroll: ₹9,37,554
- Average net salary: ₹31,251.80

## SQL Analysis Performed
- Highest-paid employees by net salary
- Average net salary by department
- Employees earning above the overall average
- Gross payroll by department
- Overtime hours and overtime costs by department
- Salary deductions by department
- Payroll calculation validation

## Skills Demonstrated
- SQL SELECT statements
- Aggregate functions: SUM, AVG, and COUNT
- GROUP BY and ORDER BY
- Filtering with WHERE
- Payroll data validation
- Data analysis and interpretation

## Disclaimer
This project uses synthetic sample data for educational and portfolio purposes only. It does not contain real employee payroll information.
