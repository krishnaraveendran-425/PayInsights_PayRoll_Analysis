# PayInsight — Payroll Data Analysis

## 📌 Project Overview

PayInsight is a beginner-friendly payroll data analysis project that explores fictional employee payroll records to understand salary distribution, departmental payroll costs, overtime payments, and employee deductions.

The project uses Excel, MySQL, and Tableau to organize data, perform analysis, and present findings through visualizations.

## 🎯 Project Objectives

- Analyze salary distribution across departments.
- Compare gross salary and net salary.
- Examine overtime hours and overtime payments.
- Understand payroll deductions.
- Identify trends and patterns in payroll data.
- Present key findings using an interactive dashboard.

## 🛠️ Tools Used

- **Microsoft Excel** — Data organization, cleaning, calculations, and analysis.
- **MySQL** — SQL queries and payroll data analysis.
- **Tableau Public** — Data visualization and dashboard creation.
- **GitHub** — Project documentation and portfolio hosting.

## 📂 Dataset Description

The dataset contains 30 fictional employee records with information such as:

- Employee ID
- Employee Name
- Department
- Job Role
- Pay Month
- Basic Salary
- HRA and Other Allowances
- Overtime Hours and Overtime Pay
- Gross Salary
- Payroll Deductions
- Net Salary

**Note:** This is a fictional dataset created for learning and portfolio purposes. It does not contain real employee payroll information.
